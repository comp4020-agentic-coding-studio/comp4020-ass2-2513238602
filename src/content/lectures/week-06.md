## Defaults with escape hatches

A default setup saves attention, but it must expose its assumptions. Connect every change in rune, first purchase, boots, or skill order to a specific lane interaction or team requirement.

Patch popularity is not evidence by itself. A setup note must state the problem it solves, the cost of choosing it, and the replay marker that will show whether it worked.

Create two matchup-specific setup cards for the same champion and explain why swapping them would make both lanes worse.
